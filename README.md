# DEMO_WEB_SHOP-AUTOMATION-PROJECT-Selenium-

## Project Description

This project is a web automation testing framework developed using Selenium WebDriver with Java. The project automates functional and regression test scenarios for the Demo Web Shop e-commerce application.

## Technologies Used

* Java
* Selenium WebDriver
* TestNG
* Maven
* Page Object Model (POM)
* Git & GitHub

## Key Automation Scenarios

* User Login
* User Registration
* Product Search
* Product Selection
* Add to Cart
* Shopping Cart Validation
* Checkout
* Logout
* Positive and Negative Test Scenarios

## Framework Features

* Page Object Model (POM)
* Reusable WebDriver methods
* Explicit waits
* TestNG annotations and assertions
* Maven dependency management
* Organized test cases and page classes
* Git/GitHub version control

## Objective

The objective of this project is to demonstrate practical knowledge of Selenium WebDriver automation, Java programming, TestNG, framework design, and web application testing.
